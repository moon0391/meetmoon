01

E. coli Promoter Classification using Canonical k-mers

Research Focus & Contribution: We investigated E. coli Sigma70 promoter classification using canonical 4-mer features and compared conventional and reverse-complement-aware representations. We evaluated both predictive accuracy and reverse-complement consistency, used SHAP to interpret feature contributions, and applied McNemar's test to assess differences in classification performance.

Results: Best classification accuracy: 82.39%  ·  Reverse-complement consistency: 100%

View GitHub Repository ↗
02

Confidence-Aware Intent Classification

Research Focus & Contribution: We developed and evaluated a confidence-aware intent classification pipeline using the CLINC150 dataset. We compared classical machine learning models, BiGRU, BERT, and ensemble approaches, and applied validation-selected confidence thresholds to detect out-of-scope (OOS) queries-inputs that do not belong to any predefined intent category. Our work focuses on evaluating intent prediction and identifying unfamiliar queries through systematic model comparison and confidence-based evaluation.

Results: Threshold-corrected BERT achieved 90.95% accuracy  ·  93.21% macro-F1.

View GitHub Repository ↗
03

Shongkot : AI-Powered Flood Crisis Intelligence Platform

Project Focus & Contribution: We developed Shongkot, an AI-powered flood crisis intelligence platform designed to support flood preparedness and emergency response in Bangladesh. The system combines machine learning-based district flood-risk prediction, interactive risk mapping, hospital recommendations, incident reporting, and authority alerts within a unified platform. Our main contribution is integrating these interconnected features into a single prototype to support better access to flood-related information and coordination during emergencies.

View GitHub Repository ↗
04

Brain Tumor Segmentation & Classification

Research Focus & Contribution: We developed and evaluated a deep learning-based pipeline for brain tumor segmentation and classification using the BRISC2025 MRI dataset. We compared U-Net and Attention U-Net architectures for tumor segmentation and evaluated an encoder-based approach for classification. Our work focuses on comparing model performance and exploring how deep learning can support automated brain tumor analysis.

Results: U-Net test Dice score: 0.6774  ·  Classification test accuracy: 88.11%
